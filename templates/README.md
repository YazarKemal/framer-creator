### Adding a template

1. Scaffold `templates/<template-name>/` with the required structure
   (see `docs/template-structure.md`).
2. Design the layout inside Framer and export the project.
3. Fill in `framer.json` and the template README.
4. Add a row to the table above.
5. Run through the `docs/marketplace-checklist.md` before submitting.
